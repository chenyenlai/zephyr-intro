# zephyr-intro

Zephyr RTOS 入門：用可以動手玩的動畫介紹執行緒與排程、中斷、號誌與互斥鎖（優先權反轉）、訊息佇列、tickless 省電、Devicetree、Kconfig、藍牙低功耗，以及怎麼寫第一個 Zephyr 程式、和 FreeRTOS 的比較。

- 網頁：https://chenyenlai.github.io/zephyr-intro/
- 移植指南：https://chenyenlai.github.io/zephyr-intro/porting.html（FreeRTOS → Zephyr，給晶片廠：學習路線、API 對照、常見問題、除錯方法）
- 每一頁都是一個獨立的 HTML 檔，沒有其他相依檔案（字型從 Google Fonts 載入）。
